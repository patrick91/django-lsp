# Completion examples

This page shows completion menus produced by `django-lsp` against the checked-in Django project
fixture. Every menu is generated by opening the example source through the real JSON-RPC service and
requesting completion at its hidden `<cursor>` marker.

The menu order is the order returned to the editor. Long menus show the first entries and the number
of additional results.

## Model fields

Completion can begin from a partial field name anywhere inside a supported query call.

<!-- django-lsp-example file=blog/views.py limit=8
from .models import Blog

Blog.objects.filter(
    ti<cursor>
)
-->
<!-- django-lsp-output:start -->
```text
from .models import Blog

Blog.objects.filter(
    ti
      ├─ title
      ├─ title__exact
      ├─ title__iexact
      ├─ title__icontains
      ├─ title__contains
      ├─ title__startswith
      ├─ title__istartswith
      ├─ title__endswith
      └─ … 7 more
)
```
<!-- django-lsp-output:end -->

## Field lookups

After a scalar field and Django's `__` separator, the server offers lookup expressions matching the
typed prefix.

<!-- django-lsp-example file=blog/views.py limit=8
from .models import Blog

Blog.objects.filter(
    title__i<cursor>
)
-->
<!-- django-lsp-output:start -->
```text
from .models import Blog

Blog.objects.filter(
    title__i
            ├─ title__iexact
            ├─ title__icontains
            ├─ title__istartswith
            ├─ title__iendswith
            ├─ title__in
            └─ title__isnull
)
```
<!-- django-lsp-output:end -->
